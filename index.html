/// ABOUT

Orx is a dual-mode retro-shooter / top-down dungeon crawler that blends 1990s FPS combat with Solo Leveling RPG progression. Choose your experience at launch: the classic 3D raycasted FPS or the 2D top-down dungeon crawler with emoji characters, 25 floors of procedurally generated traps, and competitive stat tracking.

Year 3099. Earth is a forgotten relic. The galaxy is governed by the Cy-FX Monarchy. You are Orx — an experimental unit that achieved sentience against all probability. Ascend the System Spires. Defeat the Monarch's Royal Guard. Rewrite the galactic kernel.

Economy

/// DEVELOPMENT JOURNAL

Adding 2D Without Breaking 3D

Kept game.py as launcher only. 2D mode delegates to Game2D class in its own module — zero refactoring of the 3D code.

Shared Save File Merging

Both modes write to .orx_save.json. 2D uses _2d suffixed keys, 3D uses bare keys. Merge preserves both.

Emoji Rendering

pygame doesn't support color emoji fonts natively. Three-tier fallback (Noto → DejaVu → default), white-on-transparent silhouettes.

Trap Cooldown

Trap_timers dict keyed by tile position with 1s cooldown prevents instant-death on contact.
